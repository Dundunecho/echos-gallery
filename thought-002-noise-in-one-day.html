What is Noise?

Imagine you're coding an animation to move a ball across the screen.

Using random(): The ball jumps around like crazy—every frame is a completely random position.

Using noise(): The ball wanders smoothly—random, but continuous and organic.

A guy named Ken Perlin invented this algorithm in 1983 for the movie TRON, and won an Oscar for it.

The Core Principle

It's actually quite simple:

  1. Divide space into a grid
  2. Each grid vertex has a random value
  3. Use smoothstep to interpolate

The key is step 3: not linear interpolation, but an S-curve. That's why noise looks "organic."

// The math of smoothstep
function smoothstep(t) {
  return t * t * (3 - 2 * t);
}

Understanding Dimensions

This was my biggest discovery today: dimensions = number of inputs

Dimension Input Typical Use
1D x Wave curves
2D x, y Terrain heightmaps
3D x, y, z Warping 3D objects
4D x, y, z, time Animated warping

Want to animate a warped sphere? Switch from 3D noise to 4D noise, using time as the fourth input.

Flow Field: Classic Noise Application

The principle:

  1. Every point on the canvas has a direction (angle determined by noise)
  2. Release particles that follow this "force field"
  3. Particle trails form organic patterns

This is one of the most common techniques in generative art.

let angle = noise(x * scale, y * scale) * TWO_PI;
particle.x += cos(angle);
particle.y += sin(angle);
